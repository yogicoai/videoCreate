# 편집 도구 (scripts/edit)

「팍스 산타의 선물 공장」(2026-11-09) 편집에 쓴 도구다. 모두 무료(ffmpeg + sharp)이고, **저장소 맨 위에서** 실행한다. 중간 파일은 `EDIT_WORK`(기본 `tests/.tmp/edit`) 아래에 쌓인다. 좌표는 대부분 480×854(초안 영상) 기준이다.

## 끝 카드

- `endcard.cjs <출력> [초=1.75] [로고 너비=400]`: 흰 화면 가운데 yogibo 로고 + 「요기보!」 외침. 키트는 `data/library/kits/yogibo-endcard/`.

## 움직이는 간판에 로고 붙이기

1. `find-sign.cjs <프레임.png>`, `show-sign.cjs <프레임.png> <출력.png>`: 간판 안쪽 판의 네 모서리를 찾고, 격자를 그려 눈으로 잰다. 팍스 공장 간판은 가운데 (103.75, 224.5), 너비 83, 기울기 −16.2°였다.
2. `track-sign-fine.cjs <영상> <기준 프레임> <끝 프레임> <출력.json> [찾는 폭 px] [배율 폭]`: 간판 조각으로 매 프레임 간판 가운데와 배율을 1/4픽셀까지 잰다. 기준 프레임에서 간판이 위 값에 있어야 한다(코드 맨 위 `PC`, `BOX`를 간판에 맞게 고친다).
3. `smooth-track.cjs`(한 곡선) / `smooth-pieces.cjs <json> <조각 경계 예: 640,648,672,696> <차수> <첫 프레임> <기준 프레임> <출력.json>`: 곡선으로 다듬는다. 원본이 덜컥 움직이는 프레임(signalstats YDIF가 갑자기 커지는 곳)에서 조각을 나누면 로고가 간판과 같이 움직인다.
4. `render-logo-smooth.cjs <json> <첫> <끝> <영역 x,y,w,h(2160 기준)> <반짝임 0|1> <출력 폴더>`: 로고를 2배 해상도(2160×3840 기준)로 그린다. 얹을 때 반으로 줄인다(테두리 떨림 방지). 반짝임은 빛줄기 0.45·2.1·3.75초 + 네 갈래 별.
5. `render-logo.cjs end <폴더> <프레임 수>`: 멈춘 끝 화면용 로고(1080 기준). `NOPOP=1`이면 톡 튀어나오기 없이 반짝임만.

## 장면 이음새 다듬기(긴 영상)

- `seam-analyze.cjs`: `EDIT_WORK/scenes.json`(장면 파일과 쓰는 프레임)을 읽어, 이음새마다 앞 장면 끝과 다음 장면 첫 프레임의 채널별 밝기 배율과 크기 어긋남(배율·위치)을 잰다 → `seams.json`.
- `match-zoom.cjs <넓은 화면> <당겨진 화면>`: 당겨진 화면이 넓은 화면의 어느 영역인지 찾는다(배율 1.3~2.6).
- `track-cam.cjs`: 첫 프레임 기준 카메라 움직임(배율 1.0~1.3).
- `find-pop.cjs <영상> <앞 프레임> <뒤 프레임>`: 이음새에서 갑자기 생긴 물건(뚜껑 등) 자리를 찾는다.
- `render-burst.cjs <폴더> <프레임 수> <절정 프레임> <cx,cy,R;...>`: 그 자리에 「뿅」 반짝임(둥근 빛 + 별)을 그린다(1080 기준).

## 예시(팍스 산타)

- `pin-santa/build-final.cjs <출력.mp4> [음악]`: 한 번에 뽑은 29초 영상 → 시작 간판 로고(카메라를 따라감) → 본편(원본 컷) → 끝 간판 로고 1초 → 끝 카드. 음악은 `MUSIC_DB=-7`로 깔고 loudnorm −15.
- `pin-santa/build-scenes.cjs <출력.mp4>`: 장면 7개를 이을 때 쓴 판. 장면마다 자르기, 이음새 색·크기 맞춤(1~2초에 풀기), 소리 길이 늘리기(atempo), 소리 크기 맞춤, 1프레임/3~6프레임 겹치기.
- 두 예시는 경로와 프레임 값이 팍스 프로젝트에 맞춰져 있다. 다른 프로젝트는 복사해서 값만 바꾼다.

## 크기 목업·손질(양 1탄, 2026-11-10)

생성 모델은 글로 「줄여라」라고 하면 크기를 거의 바꾸지 않는다. 참조 그림의 크기는 그대로 따른다. 그래서 무료 목업으로 크기를 먼저 정하고, 목업을 1번 참조로 「배치와 크기만 따르고 전체를 실사로 다시 그린다」고 쓴다.

- `sheep/mock-size.cjs <목표 길이(가로 1000 기준)> <출력.png>`: 제품의 한쪽 끝은 두고 나머지를 가로로 줄인 뒤, 빈 자리를 옆 풀밭으로 채운다.
- `sheep/smooth-mock.cjs <입력.png> <출력.png> [sigma=22]`: 목업 제품 안쪽의 잔주름만 편다. 파란 픽셀끼리만 섞는 정규화 흐림이라 가장자리가 번지지 않는다.
- `sheep/build-sheep-v4.cjs`: 양 편집본 예시다. 시작 작은 로고(0.3~3.6초), 끝 큰 로고(11.7초~), 음악 두 구간 교차, 「요기보!」 14.3초, 마지막 0.5초 멈춤, 1080p, −15 LUFS.
- `sheep/mock-916.cjs <16:9 그림> <출력.png>`: 가로 장면 그림을 세로(9:16, 1536×2752) 배치 목업으로 바꾼다. 양과 제품이 든 가로 띠는 그대로 두고 위는 하늘, 아래는 풀밭을 원본에서 떼어 와 채운다. `X0`·`X1`(띠의 가로 범위), `SUBJ_DST`(양·제품 바닥이 올 높이)로 조정한다.
- `sheep/overlays-916.cjs`: 양 편집본의 로고 오버레이(1920×1080)를 세로(1080×1920)로 옮긴다.
- `sheep/build-sheep-shorts.cjs <세로 영상> [출력]`: `build-sheep-v4.cjs`와 같은 구성의 세로 숏츠 편집본(1080×1920).
- `sheep/fix-end-size.cjs <첫 화면> <끝 화면> <출력> [길이 배율=1.05]`: 끝 화면에서 제품과 그 위의 양을 떼어 첫 화면 제품 크기에 맞춘 배치 목업을 만든다. 빈 자리는 첫 화면 배경과 옆 풀밭으로 메운다. 끝 화면을 그리며 모델이 제품을 키웠을 때 쓴다(세로 양 끝 화면에서 1.36배가 됐다).

## 제품 사진·장면 손질, 장면 갈아 끼우기(가족 요기보 3탄, 2026-11-10)

- `fam3/detag.cjs [폴더=prod]`: 스퀴지보 앞모습 사진 위쪽의 흰 고리 태그를 지운다. 몸통 윗선 위는 바탕색, 겹친 밑동은 좌우 색으로 메운다. 귀·뿔 같은 진한 색은 남긴다.
- `fam3/patch-tags.cjs <입력> <출력> <확인용.jpg>`: 생성 그림에 남은 작은 태그를 오른쪽 배경 조각(가장자리 부드럽게)으로 덮는다.
- `fam3/clean-book.cjs <입력> <출력> <확인용.jpg>`: 그림책 속 작은 회색 글씨를 종이 색으로 덮는다(무채색이고 종이보다 어두운 픽셀만).
- `fam3/build-fam3-fix.cjs <원본.mp4> <새3장면> <새4장면> <3장면 시작 프레임> <4장면 시작 프레임> <출력>`: 완성본의 두 장면만 새 영상으로 바꾸고 소리는 원본 그대로 둔다. 1920 폭이 아니면 lanczos로 키운다.
- `fam3/build-fam3-music.cjs <영상> <곡.mp3> <출력>`: 소리를 새 곡으로 바꾼다. atempo로 곡 끝을 영상 끝에 맞추고 크기를 맞춘다.

## 알아 둘 것

- ffmpeg 9는 `-filter_complex_script` 대신 `-/filter_complex <파일>`을 쓴다.
- sharp의 `stats()`는 앞의 `extract`를 무시한다. 잘라 낸 버퍼를 다시 읽어 잰다.
- Seedance 소리는 화면보다 약 0.07초 짧다. 무음으로 채우면 이음새마다 소리가 끊기니 `atempo`로 늘린다.
